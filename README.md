# PTE Decode Academy — website and Student/Teacher Portal

Website pages: Home, PTE Academic, PTE Core, About, FAQ, Contact, Payments, Results and Skill-Focused course, plus the Student & Teacher Portal (`portal`).
Hosted free on GitHub Pages; data is stored in the owner's Google Sheet through Google Apps Script.

PTE, PTE Academic and PTE Core are tests owned by Pearson. PTE Decode Academy is an independent training provider and is not affiliated with Pearson.
